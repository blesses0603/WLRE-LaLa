# P0 驗收標準（v0.1.0-dev）

## 離線自動化

1. `python -m unittest discover -s tests -v` 所有測試通過。
2. `python -m compileall -q lala_core lala_desktop lala_android` 無語法錯誤。
3. 重複操作被阻擋，結果不明（uncertain）不得直接重送。
4. 敏感欄位遞迴遮罩，不把原始帳密記錄至診斷。

## 待實機確認

- Windows 11 雙擊 `run_lala.bat` 能啟動畫面且沒有例外。
- 主視窗預設 1280×720、功能／清單視窗預設 800×450，所有視窗維持 16:9，不得拖曳縮放或使用最大化。低解析度螢幕啟動時可切換較小的固定 16:9 預設。
- Windows 真實視窗外框圓角 20px、主頁面板與資訊卡 Canvas 圓角；**一般按鈕須顯示原版 Btn_004，登入／開始須顯示 Btn_014，停止／取消須顯示 Btn_016，原版 MainIcon 圓形捷徑須正常顯示**。需在 Windows 11 實機檢查切片、抗鋸齒、剪裁、無黑邊、按鈕互動及 DPI。
- 所有桌面視窗均隱藏白色 Windows 系統標題列；LaLa 頁首可拖曳，主視窗能按頁首「─」最小化及「✕」關閉；功能視窗能用「✕」關閉。Windows 工作列、Alt+Tab 與還原功能需實機驗證。
- 導覽全部 27 個入口、搜尋，確認新 16:9 畫面沒有內容遮擋、截斷或凍結。
- Windows 關閉後沒有帳號密碼或伺服器連線紀錄。
- Android：觸控、捲動、介面生命週期、實機安裝（尚無 APK）。
- 正式伺服器：版本、資源、登入、角色同步、封包驗證與安全鎖（全部尚未實測）。

**完成定義：** P0 僅宣告離線 UI 骨架及共用邏輯測試完成，不宣告遊戲功能、EXE、APK 或 E2E 完成。
