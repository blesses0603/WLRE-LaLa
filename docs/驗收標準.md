# P0 驗收標準（v0.1.0-dev）

## 離線自動化

1. `python -m unittest discover -s tests -v` 所有測試通過。
2. `python -m compileall -q lala_core lala_desktop lala_android` 無語法錯誤。
3. 重複操作被阻擋，結果不明（uncertain）不得直接重送。
4. 敏感欄位遞迴遮罩，不把原始帳密記錄至診斷。

## 待實機確認

- Windows 11 雙擊 `run_lala.bat` 能啟動畫面且沒有例外。
- 導覽全部 27 個入口、搜尋、調整至最小 960×640，無凍結、遮擋與截斷。
- Windows 關閉後沒有帳號密碼或伺服器連線紀錄。
- Android：觸控、捲動、介面生命週期、實機安裝（尚無 APK）。
- 正式伺服器：版本、資源、登入、角色同步、封包驗證與安全鎖（全部尚未實測）。

**完成定義：** P0 僅宣告離線 UI 骨架及共用邏輯測試完成，不宣告遊戲功能、EXE、APK 或 E2E 完成。
