## 驗收門檻與未完成事項

- 先以模擬資料確認：首次下載、重複執行不重載、更新版本、新增與變更、下載額度、被中斷的 HTTP 回應、腐損快取、離線重查、異常路徑、符號連結、解析上限。
- 官方端點測試只讀取低負載清單及少量抽樣封包；執行時記錄提交 SHA、時刻、平台及結果，不把抽樣推論為所有素材可用。
- 需再進行完整官方下載清單的端到端驗收，包括在下載期間版本變更時拒絕報告成功、故障後再啟動及快取重用。
- 需確認 Windows/macOS 核心測試在最新提交成功；平台應用資料目錄、背景服務、Android 流量與電池政策需要 P3／P4 實際應用整合後才能驗收。
- 尚無官方可確認的數位簽章或可信 SHA-256 來源。官方索引的 MD5／CRC32 加 HTTPS 可偵測一般損毀；**本機 SHA-256** 只能驗證已保存快取的一致性，不能代替官方來源的加密認證。
- 依本專案現行 `AGENTS.md`，只維持最新版本，保留已驗證快取、失敗後重新查詢；**不提供歷史版本切換或上一版回滾**。
- 不把官方遊戲素材、快取或帳密提交 GitHub。
- 沒有正式遊戲登入、Windows／macOS Tauri 或 Android App；上述應用項目屬 P2～P4，不因 P1 核心測試成功便宣稱完成。

## 執行指令

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

官方低負載抽樣測試為 `#[ignore]`，須在允許對正式資源站測試的工作流程中明確指定；一般單元測試不自動下載官方遊戲資源。

**目前判定：P1 核心功能持續驗收，尚不能宣稱官方完整更新與跨平台實機驗收全部通過。**
