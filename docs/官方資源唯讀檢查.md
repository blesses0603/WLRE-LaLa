# 官方公開資源唯讀檢查（P1）

## 已交付

1. 先查詢先前在舊版核對的公開 HTTPS ResourcePath_PC.dat，選出最高 ExeVer 對應的 DataVer；不是硬編碼 1275。
2. 依觀察到的 DataVer，查詢 DataPackage.version 與 MainPackage.version，保留各自完整版本時間戳。
3. 明確選擇查詢 Manifest 時，再讀取兩份 .hash/.bytes；校驗 CRC32 little-endian、SHA-256 和大小；不儲存原始檔。
4. 產生包含兩包獨立版本與雜湊的確定性識別碼。即使版號相同而內容變更，識別碼仍會改變。
5. 登入閘門始終關閉。傳輸校驗並不等於資產完整解析或遊戲指令協定相容。

## 操作

Windows 從首頁進入「官方資源」功能視窗，手動按查詢按鈕。UI 背景讀取，不阻塞 Tk 主線程。

命令列：

    python -m lala_core.resource_inspector --online
    python -m lala_core.resource_inspector --online --manifests --json

不加 --online 將拒絕查詢；只有加 --manifests 才會取得 .bytes。不連線遊戲帳號伺服器。

## 安全措施

- 只允許 wlreftp.chinesegamer.net 的精確 HTTPS 公開版本／Manifest 路徑，禁止任意主機、轉址、查詢字串、未知檔案。
- 版本回應限 16 KiB，Manifest 限 8 MiB；拒絕空白、截斷、CRC32LE 不符和修訂號格式不正確。
- 不寫入原始 Manifest，不儲存角色、密碼、Token 或完整遊戲資料，不會在 UI 開啟時自動連官方站。
- CRC32 不是密碼學簽章；即使傳輸校驗通過，也不代表來源 Schema 或伺服器指令已驗證。
- HTTP／TLS 錯誤時安全停止，不回退至過時 1262／固定 1275 資料。
