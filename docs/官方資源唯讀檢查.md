# 官方資源索引與完整 Bundle 安裝（P1）

## 啟動時強制檢查

直接雙擊 `run_lala.bat`，不需手動輸入索引解析指令。啟動器依序確認：

1. Python 3.11～3.15 與 Pillow 13.0.0。
2. 官方 HTTPS `ResourcePath_PC.dat`、`DataPackage.version`、`MainPackage.version`，各包獨立完整修訂號。
3. 取得各包 `.hash/.bytes`，驗證 CRC32LE、SHA-256、長度並完整解析 YooAsset 2.2.5 Asset／Bundle 索引及相依 ID。
4. 根據**兩包全部 Bundle 紀錄**比對本機快取。重用已驗證檔案，缺少時從已核對的官方 CDN 路徑逐檔下載。
5. 每檔校驗大小、MD5、CRC32LE；原子寫入快取。下載中斷可重啟重用已完成檔案，不會發布成功收據。
6. 再次觀察官方版本及兩包 Manifest CRC，拒絕在下載期間改版造成混用；複查所有 Bundle，最後原子發布安裝收據。
7. **全部成功才允許進入 LaLa GUI**。直接使用 `python -m lala_desktop` 也必須通過本機安裝收據與檔案驗證。

Windows 私有快取：`%LOCALAPPDATA%\LaLa\official_resources`。不修改官方遊戲安裝目錄、不將 Bundle／完整 AssetPath 加入 GitHub。

## 容量、安全與失敗處理

- 預設上限 32 GiB、100,000 檔；單一 Bundle 最多 256 MiB。若超過上限、剩餘空間不足（須另保留 512 MiB）、CRC／MD5 不符、CDN 改版或資料損毀，**拒絕開啟主程式**，不能把部分下載標記為完成。
- 安裝工具：`.venv\Scripts\python.exe -m lala_core.resource_bootstrap --online --install --json`。
- `run_lala.bat --diagnose` 只查官方索引並保留診斷文字，**不下載所有 Bundle、不啟動 GUI**。
- `run_lala.bat --check` 只驗證 Python／Pillow，不連 CDN、不啟動 GUI。
- 官方 HTTPS 及 YooAsset Manifest Hash 不是程式本身的數位簽章；與當前遊戲登入協定相容性須另外驗證。
- 安裝完成僅是**資源完整性**，不是 NPC／地圖／角色資料 Schema 解碼完成，也不是成功登入；現階段 `can_login=false`。

## 回歸測試

CI 使用完全合成的 YooAsset Manifest 與 Bundle，測試正常安裝、重用、損毀重下載、校驗失敗不發布收據、磁碟配額及直接啟動阻擋。CI 不下載真實遊戲資源，不代表目前 Windows 實機已成功安裝完整官方 Bundle。

舊版參考：`wlre/services/official_version.py`、`official_manifest_sync.py`、`official_bundle_download.py` 與 `official_incremental_sync.py`。
