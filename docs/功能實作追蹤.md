## 2026-10-30：27 功能首批共用接入層與分階段實作

這次建立 `lala_core/feature_wire_bridge.py` 並實際掛到舊版登入的 `observe_readonly()` 收包回圈，**回報含全部 27 個功能，但只有 10 種已核對舊版固定長度事件可以計數**。資料不保存 Payload，且回報 `server_verified=False`；長度符合不代表正式資料同步。Windows「複製診斷」可回報匿名功能筆數；Android 預覽開始共用同份 `feature_progress` 描述，但 **Android 連線尚未建立**。

| 分類 | 功能對應 | 這次接上的部分 | 下一步驗收 |
| --- | --- | --- | --- |
| 帳號前置 | accounts、resources、settings、logs、dashboard | 原登入試驗、資源安全閘門及本機設定／診斷保留 | 端點身份、現行協定、權威持續會話 |
| 已有固定尺寸唯讀證據 | characters、companions、world、party、coop、inventory、battle、dungeons、expeditions、chat | `S8-1`、`S8-2`、`S6-1`、`S13-4`、`S186-6`、`S26-4`、`S52-1`、`S85-15`、`S31-12`、`S1-1` 匿名符合／失配計數，沒有發布遊戲數值 | 各功能舊版欄位安全解析、目前端點實測、斷線清理 |

| 舊版需求／離線功能仍待接入 | battle_ai、portals、npcs、npc_shop、storage、supplies、crafting、alchemy、skills、tent、efficiency | 保留原離線規劃或既有 UI，沒有擅自發出網路操作 | 逐項對照舊版責任／正式資源／指令與回覆 |
 
**此表共 27 個功能，0 個完成正式伺服器全鏈路驗收。** 真正「全功能接上」的驗收還需：1. 正式服身分與協定；2. 權威可重連會話；3. 27 項收包／發包及不可重送保護；4. Windows 和 Android 端到端及回歸測試。完成之前不要把封包統計或功能入口當成服務已接通。

## 2026-11-01：第一階段下一批 — S7-1／S12-1 位置事件橋接

- **程式實作**：`LegacyLoginTrial.observe_readonly()` 在既有 60 秒、4,096 筆與 8 MiB 限制內接入 `LegacyPositionProbe`；以選角 S3-1 role_id 篩選 S7-1／S12-1，本人位置、重複、他人、截斷分別計數。
- **介面**：主控台末次試驗位置標記「已結束／未認證」；複製診斷只有匿名筆數，沒有帳號、角色 ID、座標或原始 Payload。取消／重新登入清除。
- **驗收等級**：純合成單元、Fake Socket、Tk UI 冒煙測試；**S7-1／S12-1 的本人位置更新尚未取得真實伺服器端點 E2E 證據**。
- **下一缺口**：獨立核對現行官方端點、可驗證的世界事件序號或無遺失接收／完整快照重同步方式，再實作可信 `WorldSync` Adapter。不得用本機計數替代服務端 revision。

## 工程實作階段

A. 先讀取官方最新 ExeVer／DataVer 與兩包獨立修訂，依 .hash/.bytes 驗證傳輸一致性；全量 YooAsset 解析、Bundle、Schema 和協定仍要另行驗收。**不把 1262 或固定 1275 視為永久可用。**

B. 實作共用 Core 的伺服器事件與不可變權威快照。只有已完成資源及通訊協定驗證的 Adapter 可以從 fail-closed 切換成可執行。

C. 先做帳號、角色、背包、場景、效率等唯讀同步，再做隊伍、戰鬥、AI、補給、遠征、製作、煉金與交易，禁止在未知結果時重送。

D. 完成副本、協力、NPC、傳點、聊天、公會、帳篷與 Android 對應 UI／前景服務。Windows 與 Android 版本及裝置驗收須分開執行。

## 必備驗收

每功能均要具備「舊版實際程式責任 → 正式資料與協定證據 → 單元測試 → 整合／異常與重連測試 → Windows／Android 實機 → 正式伺服器 E2E」的完整追蹤。

### 本 P1 PR 已交付

- 會話世代與版本化權威快照、防 stale session、斷線清除。
- Windows 帳號／密碼遮蔽／舊版分流選擇與登入、中斷介面；只有實際驗證過的正式服 Adapter 才能讓狀態進入角色選擇，未驗證預設不發送密碼。舊版 C63-7/S63-7 只作離線格式回歸。
- 操作能力白名單、手動授權、逾時結果不明鎖定，預設不傳送任何封包。
- 本機資源的長度／SHA-256／路徑隔離檢驗；按需官方公開版本三次 HTTPS 查詢、兩包 Manifest CRC32LE／SHA-256 傳輸完整性檢驗（不代表已解碼）。
- 背包材料／預約、製作、遠征、地圖路徑及經驗統計離線計算。
- Windows 可填寫數值的本機計算視窗，保持 P0 外觀及操作習慣。
- 權威回合的技能候選規劃（預設停用、不送出）、唯讀社交通道歷史與安全白名單偏好設定。

### 禁止誤報

P1 官方公開版本與兩份 Manifest 傳輸完整性已有使用者 Windows 截圖實際驗證；**新增的 YooAsset 全量索引解析仍待在使用者目前版本的 Manifest 實機核對**。未下載 Unity Bundle、未完成遊戲資料 Schema、未核對目前正式服協定，未登入／操作／Android 實機驗收。不能宣稱 27 個功能已完成或伺服器相容。

> 2026-10-29：舊版正式分流資料取自 `WLRe_lala`，已新增手動登入／選角試驗 Adapter；**只完成模擬 TCP 測試，未在現行官方伺服器以真實帳號執行**。XOR 非加密，試驗成功也不能冒稱現行官方身分及正式遊戲會話已通過驗收。
