# P0 舊版 LaLa 介面承襲規格

查核時間：2026-10-29。
主要參照：舊桌面 wlre/ui/theme.py、theme_styles.py、dashboard_builder.py、dashboard_layout.py、overview_ui.py、function_icons.py、docs/UI_LAYOUT.md；舊 Android android_app/theme.py、dashboard.py、widgets.py。

## 原則

新版保留舊版 LaLa 的深藍青色玻璃感、首頁資訊排列及操作習慣，實際程式保持新式的共用 Python 核心與分離的 Windows／Android 介面。不是直接搬移舊版複雜的 State、Socket 或事件耦合。

## Windows 版

- 原舊版 1280×800 畫面比例改為新版固定 **16:9**：主視窗預設 1280×720，功能及清單視窗預設 800×450。所有視窗禁止使用者拖曳縮放與最大化；若螢幕較小，啟動時才選擇較小的 16:9 固定尺寸。
- 沿用主色背景 #101c2b、面板 #142638、標題青色 #62c9e0、區塊青藍描邊。主視窗外框採 20px 圓角（Windows Win32 裁切）、內部資訊卡 13px、面板 16px、按鈕 11px；不改字色與功能邏輯。
- 移除 Windows 原生白色系統標題列（Tk override-redirect），保留深藍色 LaLa 頁首與登入／選角入口；頁首可拖曳，主視窗有自訂最小化與關閉鍵；功能視窗有關閉鍵。
- 左側十張主頁卡：角色與夥伴、目前活動、自動戰鬥、自動徘徊、遠征、補給紀錄、煉金、製作、隊伍檢查、經驗效率。
- 左上圓形快捷入口、左下聊天、右上小地圖、右下事件紀錄與戰場陣形分頁。
- 功能以獨立非模態視窗開啟；保留全部 27 項功能的可搜尋入口。

## Android 版

- 深藍＋青色圓角科技卡片（沿用舊 Android 視覺語彙）。
- 可橫向滑動的圓形快捷入口與適合觸控的獨立功能頁。
- 主頁延續角色、活動、遠征、背包、地圖與事件概況入口。

## 暫不直接搬入舊遊戲素材

原版 EXP 插畫與功能 PNG 涉及遊戲素材。P0 目前只重製版面、顏色及圓形底板，以文字圖示暫代原版圖片。後續確認素材授權與版本來源後再加入可選資源，缺圖時須可正常降級。

## 測試與限制

- 本階段完成 UI 原型程式碼及純 Python 版型契約測試。
- 16:9、不可縮放、無原生標題列、圓角元件及不可最大化列入 UI 契約與 Xvfb 煙霧測試；真正 Windows Win32 視窗外框圓角、工作列／Alt+Tab／最小化還原、HiDPI 多螢幕仍待 Windows 11 實機驗收。
- 尚未執行 Android 實機觸控、APK 與繁中字型驗收。
- 尚未導入真實地圖、戰場、聊天、角色資料、官方背景或伺服器連線。
- 預覽畫面以「尚未同步」顯示未知狀態，不以假 HP、假座標或假操作結果誤導。

維持桌面與 Android 各自的 0.1.0-dev 版本，僅在既有 PR #1 累積 UI 調整，不再升版。
