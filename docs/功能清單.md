# 舊版功能 → 全新 LaLa（P0 第一輪盤點）

2026-10-29 以舊版桌面 `WLRe_lala/main` README、架構文件與目錄，及舊版 Android `WLRe_lala_Android/main` README、程式目錄作為需求參考。

`lala_core/features.py` 暫列 **27 個功能入口**與舊版責任範圍。這是導航與需求清單，**不代表 27 個功能已實作**，亦不代表逐函式／封包核對完成。

## 分組

- 總覽：主控台
- 帳號：多帳號登入、角色資訊與能力配點
- 戰鬥：手動戰鬥、AI、隊伍與陣形
- 探索：小地圖、導航、傳點、NPC 與商店
- 物品：背包、倉儲、補給、修理整理、製作、煉金、技能
- 活動：夥伴、遠征、一般副本、協力挑戰
- 社交：聊天、公會、帳篷與家具
- 系統：經驗統計、官方資源、診斷、設定

## 新版架構要求

1. 角色、背包及操作結果只能取自可信伺服器回覆，不能創造虛假狀態。
2. UI 不直接存取 socket，需透過共用 Core 的命令、事件及狀態快照。
3. 操作逾時或不明結果不可盲目重送，須經權威狀態同步後才解除鎖定。
4. 官方資料版本符合不代表遊戲協定相容，也不代表端到端驗收成功。
5. GitHub、Log、測試檔及打包產物不得含真實帳密、金鑰或未授權遊戲資源。
6. Windows 與 Android 可用不同 UI，服務生命週期可依平台設計，共用業務核心。
7. 後續逐項建立「舊版行為 → 新版模組 → 離線測試 → 正式服驗收」對照表。

本階段尚未實際登入正式伺服器。
