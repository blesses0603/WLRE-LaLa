# 架構及版本規劃

共用核心使用 Rust，未來負責遊戲協定、登入狀態、戰鬥及資源管理。Windows 與 macOS 使用 Tauri 並維持一致介面；Android 使用 Kotlin 與 Jetpack Compose。平台透過明確的核心介面及儲存適配器整合，避免重複實作核心邏輯。這些平台應用及遊戲邏輯尚未實作。

資源管理先提供與來源格式無關的相對路徑、資源清單比較、儲存介面、錯誤碼與可序列化 JSON 事件。清單的識別值由未來經確認的來源轉接器提供，不能視為已驗證的雜湊。比較結果只包含新增及變更，不會刪除本機檔案。介面不保證檔案系統安全：實際適配器必須防止符號連結逃逸、處理平台名稱衝突，並以暫存及原子替換保護更新。

後續依調查結果實作更新偵測、增量下載、已確認格式的安全解析與提取、完整性驗證、快取、失敗恢復與回滾、各平台儲存適配及進度日誌。不得將未確認的機制當作事實。

共用核心已整合 0.1.0，本次預計整合 0.2.0；桌面版及 Android 版尚未設定版本。三者獨立演進，但所有 PR 版本號必須全域唯一；建立 PR 前檢查所有現有 PR。版本號為 PR 識別，不代表已發布。

## 共用核心介面與日誌基線

目前工作區有共用可觀測性套件與資源管理套件。資源管理與平台儲存以 `ResourceStorage` 邊界區分；介面讀取已驗證的相對路徑，回傳檔案內容、檔案不存在或錯誤碼。介面尚未提供寫入或原子替換，不能用來宣稱已實作跨平台快取。未來網路、協定、登入與戰鬥分別負責傳輸、已確認封包、狀態及規則，這些模組及對外呼叫介面尚未建立。平台整合、執行緒、生命週期與資料所有權需在實作 FFI／JNI 前訂定並測試。

共用可觀測性套件定義版本化 JSON 行事件及跨模組錯誤碼，資源管理使用相同的錯誤碼型別。事件欄位為 `schema_version`、`event`、`completed`、`total`、`error`；事件名稱與錯誤碼使用固定的大寫底線代碼，無錯誤時 `error` 為 null。寫入介面接受呼叫端提供的輸出目的地，回傳寫入錯誤；失敗可能留下部分資料，多執行緒同步、檔案輪替與輸出生命週期由平台負責。事件型別不接受自由文字、路徑、帳密、權杖或封包，避免由此介面輸出秘密。現有的事件種類只有資源更新進度，計數準確性由呼叫端負責；其他模組、平台接線、時間戳與實際更新進度來源尚未實作。新增事件或代碼需維持既有意義並補上序列化與錯誤路徑測試。

`.gitignore` 僅阻擋已列出的常見本機路徑與憑證副檔名，不能辨識所有遊戲素材或秘密，也不會移除已追蹤檔案；提交前仍須檢查內容。

## 內容定址快取的初步範圍

資源管理提供單一已觀察官方封包目錄的同步下載介面，呼叫端須提供可信的 SHA-256 與預期大小，並使用私有、可信且不受其他不可信程序寫入的既有快取目錄；程式不檢查祖先目錄的安全性，亦不防禦可同時修改該目錄的程序。下載禁止重導向，限制單檔大小和逾時，先寫入同目錄暫存檔，驗證大小和 SHA-256 後才以不覆寫方式放入以雜湊命名的快取；命中時重新檢驗內容，損毀時失敗，不覆寫原檔。呼叫端需要控制排程及頻率。此介面不提供官方 SHA-256 的來源，現有官方索引欄位不能當成可信 SHA-256；因此尚未串成官方自動更新流程。未提供檔案提取、快取索引、版本切換、失敗復原或回滾，也未驗證強制中斷、跨平台持久化或惡意程序並行修改。


增量預覽可依精確封包名稱與依賴閉包連接下載，執行前先檢查所有選定項目的可信 SHA-256 與檔案數、總量上限；缺少任一可信摘要或超出額度時不開始下載。下載目前僅支援實際觀察到的 Windows／Android `1.3.21` 與 Windows `1.3.22` 目錄，其他版本拒絕。官方索引目前沒有已確認的可信 SHA-256 來源，呼叫端不得把 MD5／CRC32 假冒為 SHA-256；因此此串接尚不能自行完成官方更新。多檔下載中途失敗時已驗證的快取物件保留，但沒有版本啟用、交易式回滾或崩潰恢復。


版本狀態基礎以單一狀態檔記錄目前與上一版本；切換與回滾前會重新驗證所需快取物件，狀態資料以同目錄暫存檔替換，讀取時忽略孤立暫存檔。此功能要求根目錄與祖先私有可信、呼叫端保證只有一個寫入者；尚無跨程序鎖、斷電後目錄持久化、舊版本完整索引或全平台實機驗收，亦尚未接入更新下載與遊戲應用。損毀的目前狀態不會自動被覆寫，需由後續修復流程處理。


排程基礎使用呼叫端提供的單調時間，限制正常間隔、避免重疊及對失敗套用有限退避；不自行啟動背景工作或持久化，也未接到 Windows／macOS／Android 平台排程與行動電量、流量政策。呼叫端需處理執行中工作取消與程序重啟後的狀態。
